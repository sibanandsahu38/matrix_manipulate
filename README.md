# 📖 Overview

**Matrix Engine Studio** is an advanced browser-based matrix calculator built using **HTML, CSS, and JavaScript**.

It provides an intuitive interface for solving both basic and advanced matrix operations while supporting **complex numbers**, **interactive matrix visualization**, and **step-based numerical algorithms**.

The application is designed to simplify linear algebra concepts through an elegant and responsive user interface.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/sibanandsahu38/matrix_manipulate.git
```

Navigate to the project directory

```bash
cd matrix_manipulate
```

Open **index.html** in your preferred web browser

or

Use **Live Server** in VS Code for the best experience.

---

# ▶️ Usage

1. Select the desired matrix operation.
2. Enter matrix dimensions.
3. Input matrix values (real or complex).
4. Click **Calculate**.
5. View the computed result.
6. Explore step-by-step output (where applicable).
7. Visualize matrix transformations using the visualization panel.
